Méthodologie

7 jours glissants

Chaque chiffre couvre les 7 derniers jours, comparés aux 7 précédents. Cela lisse les week-ends. Les vacances scolaires font baisser l’activité : une baisse n’est pas forcément un mauvais signe.

Calcul

Les données publiées sont des cumuls par domaine de messagerie. Les flux sont les différences d’un jour à l’autre. Les jours non publiés sont rattrapés le jour suivant : les totaux restent justes, mais les fenêtres de 7 jours concernées ne sont pas tracées sur le graphique. L’intensité rapporte les messages de la semaine au parc moyen de cette semaine : un compte créé vendredi ne compte pas comme s’il avait été disponible 7 jours.

Académies qui se démarquent

Tous les pourcentages comparent les 7 derniers jours aux 7 précédents. Une académie est signalée si son évolution s’écarte d’au moins {{ signal_thresholds.min_gap_pts }} points de l’évolution nationale, avec au moins {{ signal_thresholds.min_base.new_users }} comptes ou {{ signal_thresholds.min_base.messages }} messages la semaine précédente. Les effets communs (vacances, rentrée) s’annulent. Un signal invite à investiguer, il ne juge pas une performance. En dessous de ±{{ signal_thresholds.stable_pct }} %, une évolution est considérée stable.

Carte

Un volume élevé reflète d’abord la taille de l’académie : le nombre d’agents éligibles n’est pas connu. La vue Intensité rapporte les messages à la taille du parc : c’est la plus adaptée pour comparer les académies. Seuls les domaines rattachés sans ambiguïté à une académie sont cartographiés.

Limites

Mesuré : comptes créés et messages envoyés. Non mesuré : utilisateurs actifs, rétention, fréquence d’usage, impact sur les pratiques.
